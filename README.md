# Prompt Builder Criadas — V6.8.13

Actualización incremental sobre V6.8.12 Stable, manteniendo la base funcional.

## Cambios incorporados

- Unificado el segundo personaje: se elimina el menú redundante «Presencia secundaria». «Rol del segundo personaje» controla ahora la presencia secundaria.
- Si el segundo personaje es «Criada», se activan «Interacción con la segunda criada» y «Uniforme segunda criada», y el aviso exige IMAGE A + IMAGE B.
- La segunda criada puede trabajar junto a la protagonista y mantener contacto visual natural cuando la acción lo justifica.
- Menú de perros independiente conservado.
- Nueva pose «Ligera reverencia».
- Cofias formales corregidas: posición baja tipo tiara/diadema, aproximadamente a la altura de las orejas; nunca encaramadas sobre la coronilla.
- Nuevo «Servicio — delantal con pitet/babero y encaje».
- Bloqueo global de cero botones en cualquier superficie del delantal. La oclusión física del delantal prevalece sobre el número de botones visibles del vestido.
- «Composición» queda reservada a distribución espacial; puerta, ventana, espejo, POV, vigilancia y observador oculto se concentran en «Composición narrativa».
- «Ángulo» queda reservado a altura/inclinación física de cámara.
- «Referencia fotográfica» se trata como modificador estético secundario: nunca puede contradecir iluminación, emoción, momento narrativo, composición, cámara, actividad o uniforme seleccionados.
- Referencias fotográficas consolidadas en cinco opciones.
- «Momento narrativo» simplificado eliminando redundancias.
- Añadidos cuatro estilos visuales: Fotografía cinematográfica, Fotografía analógica, Ilustración plana con contorno de lápiz/tinta y Acuarela editorial.
- Presets con nombre: Guardar, Cargar, Duplicar y Eliminar muestran ahora un diálogo real para elegir el preset.
- Se conserva el borrador automático de trabajo en localStorage para recuperar la configuración tras una recarga.
